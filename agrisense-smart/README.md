# AgriML - Smart Farming Through Data-Driven Intelligence

## Project info

Integrated Crop Recommendation, Soil Correction & Fertilizer Advisory System using Machine Learning. Get AI-powered agricultural insights for sustainable farming.

## Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies:
```sh
npm install
```
3. Start the development server:
```sh
npm run dev
```

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
